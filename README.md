# Hsu-Chao Lai — Academic Website

Source for [hcltw.github.io](https://hcltw.github.io/), built with Hugo and the Hugo Blox Academic CV theme.

## Local development

Requirements: Hugo Extended 0.148.2, Node.js 20, and pnpm.

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

The site is deployed to GitHub Pages by `.github/workflows/deploy.yml`.
